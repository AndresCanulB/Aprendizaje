- Todos los comandos de Git son iguales en todos los sistemas operativos.

- Para saber que tenemos instalado Git:

    git

- Configuración Inicial

    git config --global user.name "AndresCanulB"
    git config --global user.email "acanulb70494@gmail.com"


- Ver la configuracion global:

    git config --global --list

- Inicializa un nuevo repositorio de Git en el directorio actual.

    git init

    - Se creará un fichero oculto .git

- Cambia la rama local de master a main

    git branch -m main

- Cambia el nombre de la rama por defecto de master a main:

    git config --global init.defaultBranch main

- Ver el nombre de la rama por defecto:

    git config --get init.defaultBranch
